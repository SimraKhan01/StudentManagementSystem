# Student Management System  

This is a basic Student Management System built in Python.  
It allows you to add, view, update, and delete student records.  

The project was created as part of my Computer Engineering diploma to practice Python and file handling.  

## Features  
- Add new student details  
- View all student records  
- Update existing student information  
- Delete a student record  
- Stores data in a text file for persistence  

## Technologies Used  
- **Python 3** (Core programming)  
- **File Handling** for storing records  

## How to Run  
1. Clone this repository or download the files.  
2. Run the script in your terminal/IDE:  
   ```bash
   python student_management.py
